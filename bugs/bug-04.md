# BUG-04: Буруу JSON биетэй POST /api/books хүсэлтэд 400 биш 200 OK буцаана

Орчин: Уншлагын жагсаалт v2.0, curl (Git Bash), Windows 11, 2026-10-25

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Хоёр дахь Git Bash цонхонд дараах командыг ажиллуулна:

   curl -s -i -X POST http://localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title": broken'

2. Хариуны эхний мөр болон биеийг харна.

Хүлээгдэж байсан: Спецификац: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана».

Бодит үр дүн: Хариу нь «HTTP/1.1 200 OK», бие нь {"result":"OK"}.

Ноцтой байдал: Major, буруу хүсэлтийг амжилттай гэж хариулснаар клиент алдааг мэдэхгүй.
