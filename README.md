## Дүгнэлт (debrief)

Хамгийн үр дүнтэй аялал нь Supermodel байсан, учир нь тоолуурын зөрүү, ногоон устгах товч, ажиллахгүй линк гэсэн 3 согогийг зүгээр л апп-ыг хараад олсон. Couch Potato аялалаар Он талбар хоосон байхад ном нэмэгдэж байгааг олсон. Saboteur аялалаар curl ашиглаж, буруу JSON-д 400 биш 200 OK буцдаг API согогийг олсон. Fed-Ex аялалаар өгөгдөл тоолуур хүртэл зөв дамжиж байгаа эсэхийг шалгахад тоолуурын утга бодит жагсаалттай зөрж байгааг. Charter-аас гадуур санамсаргүйгээр хүснэгтийн эвдрэл гэдгийг олсон. Автомат Playwright тест тоолуурын тоо, статус код, линкийн хариуг барьж чадах байсан, учир нь эдгээрийг тодорхой утгаар шалгаж болно. Харин товчийн өнгө, хүснэгтийн эвдрэл, мессежийн утга зүйн алдааг зөвхөн хүний нүд л олох байсан. Нийт 4 согог баримтжуулсан.
